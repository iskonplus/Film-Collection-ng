About the App

Movie Collection is a simple Angular application designed to demonstrate modern frontend development practices.

The app allows users to browse a collection of movies, search by title, view detailed information about each film, and mark movies as favorites.

This project is built using Angular standalone components and focuses on key concepts such as routing, signals for state management, custom pipes, and reusable UI components.

All data used in the application is mock data, and the main goal of the project is to showcase clean architecture and reactive UI patterns without using RxJS.

The application is structured in a modular way, separating core logic, shared components, and feature-specific functionality to ensure scalability and maintainability.

This project was created as part of a learning process to strengthen Angular skills and understand how to build a well-structured single-page application.
